# AXIS appendix reproducibility archive

This versioned archive preserves the technical appendix accompanying the AXIS
thesis on 6 November 2026, before its requested reduction. The thesis retains
the experimental design, results and interpretation-changing qualifications;
these files supply the full implementation and provenance details.

Each section has a readable Markdown copy and the exact UTF-8 LaTeX excerpt.
The `.tex` excerpts are the authoritative transcription when Markdown rendering
differs. They are source fragments, not a standalone thesis project. Cross-reference
numbers in the readable copies refer to the archived thesis state; source labels
are retained in the LaTeX copies. No new training, inference or statistical results
were generated by this archival operation.

## Preservation checks

`manifest.json` records every payload's SHA-256, section mapping and the source
appendix hash. Run `python supplementary/appendix-reproducibility/verify.py`
from the repository root, or `python verify.py` from this directory. Verification
checks the archived bytes and section identities; it does not rerun experiments.

For citation, use a GitHub URL containing the full commit ID rather than a moving
branch name. The shortened thesis links each appendix section to its matching
readable archive at one immutable commit.
